### 1. Asset Verse — Asset Management System
**Short Overview:**  
Asset Verse is a full-stack MERN enterprise asset management platform. It allows organizations to seamlessly track, allocate, and document company assets while managing employee requests and HR workflows.

* 🌐 **Live Demo:** [Asset Verse Web App](https://stupendous-gumption-565b2dsmsagor123.netlify.app)
* 🛠️ **Tech Stack:** React, Node.js, Express.js, MongoDB, Firebase, Tailwind CSS, Recharts, Stripe API.
* ✨ **Key Features:**
  * **Employee Portal:** Request new assets, track assigned gear, and initiate returns with custom filters.
  * **HR/Admin Dashboard:** Complete inventory control (CRUD operations), request management, and PDF report generation.
  * **Role-Based Access Control (RBAC):** Firebase Authentication integrated with role-specific navigation and secure routing.
  * **Payment Integration:** Integrated Stripe for premium membership/asset tiers.

## Asset Verse Project
## Description
Asset Verse is a MERN full-stack asset management system designed for companies.  
Employees can view and request assets, while HR/Admin can manage employees, assets, and generate reports.  
It helps track, return, and document company assets efficiently.

## short project overview.
Asset Verse is a MERN full-stack asset management system that helps companies track, manage, and allocate assets efficiently. Employees can request and return assets, while HR/Admin can manage inventory, monitor requests, and generate reports in a streamlined dashboard.

## Live Link
https://stupendous-gumption-565b2dsmsagor123.netlify.app

## Technologies Used:
React, Node.js, Express.js, MongoDB, Firebase, TailwindCSS, Recharts, Stripe


##Key Features

### Employee Dashboard
- View assigned assets
- Request new assets
- Return returnable assets
- Search and filter assets

### HR/Admin Dashboard
- Manage employees
- Manage assets (Add/Update/Delete)
- View all requests and approvals
- Generate PDF reports of assigned assets

### Profile Pages
- Employee profile
- HR/Admin profile with role-specific menus

### Authentication & Security
- Firebase email/password login
- Role-based access control (Employee / HR/Admin)
